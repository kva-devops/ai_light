# Световой консультант

Русскоязычный веб-чат для дизайнеров интерьера. Клиент хранит историю только в памяти текущей вкладки; сервер проверяет входные данные, применяет системный промпт и обращается к ProxyAPI. База данных, cookies и постоянное браузерное хранилище не используются.

## Требования

- Node.js 20+
- ключ ProxyAPI

## Локальный запуск

1. Установите зависимости: `npm install`
2. Положите ключ одной строкой в `apikey.txt` в корне проекта **или** задайте переменную `PROXY_API_KEY`.
3. Запустите: `npm run dev`
4. Откройте `http://127.0.0.1:3000`

`apikey.txt`, локальные `.env`-файлы, сборки и логи исключены из Git. Никогда не добавляйте ключ в клиентский код или репозиторий.

## Проверка и сборка

```bash
npm test
npm run build
```

## Запуск на обычном Node.js-сервере

```bash
npm install
npm run build
NODE_ENV=production PROXY_API_KEY=ваш_ключ npm start
```

На Windows задайте переменные окружения способом, принятым в вашей оболочке или панели хостинга. Сервер слушает `127.0.0.1`; для публичного доступа разместите перед ним reverse proxy (например, Nginx) с HTTPS.

## Конфигурация

Скопируйте `.env.example` как памятку по параметрам. Встроенные значения:

- модель: `openai/gpt-4o-mini`
- адрес: `https://api.proxyapi.ru/v1/chat/completions`
- тайм-аут: 30 секунд
- максимум: 10 запросов за 5 минут с одного IP
- одновременно: до 2 запросов с одного IP
- до 20 сообщений в контексте, до 2 000 символов в сообщении

Системный промпт находится в `server/system-prompt.md`. Проверяемая арифметика расчёта освещения реализована в `server/lighting.ts` и вызывается моделью как серверная функция.
